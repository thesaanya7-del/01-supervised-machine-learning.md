What Is Supervised Machine Learning?

Supervised Machine Learning is a type of machine learning in which a model learns from labelled data.

Labelled data contains input information and the correct output.

The model learns the relationship between inputs and outputs and uses that knowledge to predict answers for new data.

💡 Real-Life Example

Imagine teaching a student using examples of houses and their prices.

Input (House Size)

Correct Output (Price)

500 sq. ft.

₹10 lakh

1,000 sq. ft.

₹20 lakh

1,500 sq. ft.

₹30 lakh

The model studies these examples and learns patterns between house size and price.

⚙️ 3. How Does Supervised Learning Work?

📊 Collect labelled data.

🧹 Clean and prepare the data.

🎯 Identify the input features (X) and target (y).

✂️ Divide the data into training and testing sets.

🧠 Train the model using training data.

🔮 Make predictions on new data.

📈 Evaluate the model's performance.

🧩 4. Important Terminology

Term

Meaning

📚 Dataset

A collection of data examples

🔹 Features (X)

Input variables used for prediction

🎯 Target (y)

The output the model learns to predict

🏷️ Labelled Data

Data containing inputs and known answers

🧠 Training

Learning patterns from examples

🧪 Testing

Evaluating the model on unseen examples

🔮 Prediction

The model's estimated output

⚠️ Overfitting

When a model fits training data too closely and struggles with new data

🟣 5. Types of Supervised Learning

🟢 A. Regression

Regression predicts a numerical value.

Examples:

House prices

Crop yields

Salaries

Temperature

🔵 B. Classification

Classification predicts a category or class.

Examples:

Spam or not spam

Fraud or legitimate

Loan approved or rejected

Positive or negative review

✅ 6. Advantages

Learns from labelled examples.

Predicts outputs for new inputs.

Supports both numerical prediction and classification.

Can solve problems in many industries.
⚠️ 7. Limitations

Requires labelled training data.

Poor-quality data can produce unreliable results.

Biased data can lead to biased predictions.

Complex models may require more computing resources.
